## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## Características

- Visualización de resultados de votaciones por candidatura, partido político y candidatura independiente.
- Análisis de resultados a nivel de distrito electoral y alcaldía.
- Selección dinámica de distritos electorales y alcaldías mediante un panel lateral interactivo.
- Navegación fluida entre diferentes tipos de visualización de datos.
- Integración con servicios de API para obtener y procesar datos en tiempo real.
